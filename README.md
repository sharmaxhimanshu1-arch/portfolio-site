# Himanshu Sharma: portfolio

A single-page portfolio for a content and social media specialist. Plain HTML, CSS and a little JavaScript, with no build step.

## Run it locally

Open `index.html` in a browser.

## Deploy

Netlify serves the folder as-is (see `netlify.toml`). Any static host works.

## Edit

All content, styles and scripts live in `index.html`.
